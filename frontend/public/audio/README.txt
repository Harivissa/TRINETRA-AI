Audio files go here.

Per-country ambient audio (Country Intelligence page):
  Named by country ID — IND.mp3, CHN.mp3, USA.mp3, etc.
  Plays while that nation's profile is open, stops on leaving/switching.

Loading engine audio (plays during the ~9s full-screen analysis loading screen):
  File name must be exactly: loading.mp3
  Plays once when the loading engine mounts, stops when it finishes.

Not included by Claude — copyrighted music/movie audio can't be sourced
or reproduced, including short dialogue clips. Any royalty-free audio or
your own recordings work fine; just name the file as above and drop it
in this folder. Nothing needs to be rebuilt or restarted — refresh the
page and it picks it up automatically. If the file isn't there, the
loading engine and audio buttons just silently continue without sound.
